# AI Call Transcription & Summary Service

## Pages & Features

### 1. Dashboard
- Total calls transcribed today / this week
- Average transcription accuracy score
- Processing queue status
- Storage usage overview

### 2. Transcription Feed
- Real-time transcription during live calls
- Speaker diarization (who said what)
- Timestamp & paragraph segmentation
- Confidence score highlighting for uncertain words

### 3. Call Library
- Searchable archive of all transcripts
- Filter by date, caller, duration, topic
- Full-text search across all transcriptions
- Favorite / bookmark important calls

### 4. AI Summaries
- Auto-generated call summary (key points)
- Action items & follow-up tasks extraction
- Decision log per call
- Sentiment & tone summary

### 5. Export & Sharing
- Export transcript as PDF / DOCX / TXT
- Share transcript link with team
- Copy summary to clipboard
- Push to CRM / project management tool

### 6. Analytics
- Transcription volume trends
- Top topics & keywords word cloud
- Average call duration & talk-time ratio
- Sentiment distribution over time

### 7. Settings
- Language & dialect configuration
- Custom vocabulary & jargon dictionary
- Speaker profile management
- Retention & auto-delete policies
- API & webhook configuration
